# Real Estate Price Prediction (Deep Learning Final Project)

This repository contains a Jupyter Notebook that trains a Deep Neural Network to predict California housing prices based on demographic and geographical features. 

## How to Run
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Launch Jupyter: `jupyter notebook`
4. Open `real_estate_price_prediction.ipynb` and run the cells sequentially.
